# Honor-Helper
纯vibe coding作品，代码未经审查，可能会存在问题。

支持脱离荣耀系软件切换性能模式，为自定义程序开启时切换性能模式和进行GPU超频。

仅支持荣耀winh7笔记本

详见[架构说明](docs/architecture.md)。
